# Mobile Full Experience — Final certification matrix

## Goal

Certify the complete Mobile Full Experience software surface on one immutable candidate without re-implementing lot-specific harnesses and without pretending that browser CI can prove physical-device behavior.

## Success

The software gate is green only if every selected backend contract, every selected frontend/foundation contract, and the guarded frontend build succeed on the exact same Git commit.

Global Mobile closeout additionally requires the physical-only human gates listed below. A green software run alone MUST NOT be recorded as proof of those physical behaviors.

## Physical-only human gates

These cannot be truthfully certified by Ubuntu/browser CI and remain explicit before global Mobile closeout:

1. Face ID unlock on a supported iPhone.
2. Touch ID unlock on a supported Apple device if part of the supported device set.
3. Android biometric unlock on a supported Android device.
4. Real Push notification reception while the installed PWA is backgrounded/closed, with generic lock-screen payload and authenticated deep-link reopening.
