## Décision après vérification des sources primaires

**Aucun corpus panoramique comportant la numérotation FDI-32 n'est à ce stade simultanément démontré (1) utilisable commercialement, (2) juridiquement traçable image par image, (3) autorisé à être traité sur des machines GitHub cloud, (4) sans restrictions séparées et (5) techniquement exploitable sans contamination entraînement/test.** Les licences déclarées ne suffisent pas à combler la chaîne de droits cliniques. La décision d'entraînement réel est donc **NO-GO**. Il faut garder une distinction entre **licence du code**, **licence de l'article**, **licence du jeu d'images original**, **conditions additionnelles** et **droits de traitement externalisé**.

### Règle de levée de blocage

Ne considérer **commercial dataset READY** qu'après accès à la *source originale* des images, preuve explicite de droits de réutilisation et formation commerciale, droit de recours au service cloud GitHub/tiers ou environnement contractuellement approprié, respect des protections données de santé applicables, absence de restriction NC/DUA contradictoire, 32 labels réels vérifiés, patient-level splitting avant augmentation, validation indépendante. Cette étape requiert une revue de droits humaine documentée ; modifier une étiquette `license` dans le JSON, un README ou dans Roboflow ne lève pas le blocage.

**Alternative pour créer un jeu juridiquement contrôlé** : définir un corpus d'origine sous contrôle légal documenté (droits, traitement, dé-identification, autorisations) et demander l'annotation professionnelle des 32 positions par dent. Il peut être traité ultérieurement par GitHub Actions uniquement si son cadre juridique autorise précisément le traitement sur ces runners. Aucun transfert de clichés issus du cabinet dans la présente PR.

**Rappels stables** : [J10L #1023](https://github.com/hraaaaf/Digital_crown/pull/1023) a déjà démontré sous GitHub Actions le **calcul d'un gradient avec tête artificielle 32 FDI**, sans apprentissage des dents. Ces exercices synthétiques ne signifient pas modèle commercial prêt. Le **PDF panoramique reste 100 % écrit**, aucune image X-ray intégrée, radiographie séparée dans Imagerie. Toutes les PR restent DRAFT / sans merge ni déploiement.
