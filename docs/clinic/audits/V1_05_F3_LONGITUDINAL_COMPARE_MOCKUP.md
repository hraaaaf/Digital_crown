## Desktop 1280×900

Header row:
- icon + “Comparaison orthodontique”
- neutral helper: “Comparer deux repères du traitement”
- right-aligned evidence count

Selector row:
- left card: T0 selector + date + evidence badges
- center swap control
- right card: T1 selector + date + evidence badges

Evidence lane:
- two balanced columns
- canonical evidence chips/cards only:
  - Photo / Media Core
  - Céphalométrie
  - Panoramique
- each item shows source type + reference id + date
- no image duplication in F3 persistence

Measurement panel:
- compact 4-column table
  - Mesure
  - T0
  - T1
  - Δ numérique
- signed delta only, e.g. +1.2° / -0.8 mm
- no green/red “better/worse”
- no success/progress label
- caption: “Variation numérique — interprétation clinique par le praticien.”

## States

1. No OrthoCase / no timepoints:
   - surface may stay absent

2. One timepoint only:
   - compact neutral card:
     “Un second timepoint est nécessaire pour comparer.”

3. Two or more timepoints:
   - default pair = earliest and latest available ordinal
   - user can change either selector

4. Evidence missing on one side:
   - show “Aucune preuve liée” only for that evidence lane
   - do not infer absence of treatment activity

5. No shared cephalometric measurements:
   - evidence comparison remains available
   - measurement panel says “Aucune mesure céphalométrique commune.”

6. Error:
   - fail closed with neutral retry state
   - no empty-state inference from backend failure

## Clinical neutrality

Sources on cephalometric reproducibility and longitudinal measurement error justify a neutral presentation:
- AlBarakati SF, Kula KS, Ghoneima AA. Dentomaxillofac Radiol. 2012;41(1):11–17. doi:10.1259/dmfr/37010910.
- European Journal of Orthodontics. 2002;24(6):655–665. doi:10.1093/ejo/24.6.655.

F3 therefore displays raw values + arithmetic deltas only. No clinical interpretation is generated.
