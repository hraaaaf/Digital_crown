## Sources normatives et portée exacte

Ce contrat **ne modifie pas** la politique de release existante et ne crée pas une deuxième autorité : [docs/CABINET_CERTIFIED_RELEASE_POLICY.md](../CABINET_CERTIFIED_RELEASE_POLICY.md), `.github/workflows/cabinet-release-certification.yml`, `DigitalCrown.spec`, `run.py`, `installer/DigitalCrown.iss`, `docs/quality/REALITY_PROOF_GATE.md`, `docs/handovers/2026-11-07-restore03-installable-candidate-preflight.md`, `docs/v1.5/V15_08_2_B_DESKTOP_LAB_FUE_G_20261109.md`, `docs/v1.5/V15_08_2_B_MAIN_ENTRYPOINT_FUE_I_20261109.md`, `docs/v1.5/V15_08_2_B_B5B_CI_ISOLATION_FIX_20261109.md`.

**Règle absolue :** le seul objet qui pourra être installé/activé est une release `INSTALLABLE_CERTIFIED`, dérivée d'une `CODE_CERTIFIED` **sur le HEAD exact de `master`** et d'assets runtime certifiés au même SHA, avec provenance GitHub/Sigstore vérifiée. Un commit PR, un CI PASS, un FUE-G navigateur ou un build ad hoc ne sont jamais installables. Le merge, la certification master, la composition des assets, le packaging, l'installation et l'activation sont des opérations distinctes **non autorisées par le présent GO**.

## Préflight reproductible, non destructif

Outil en lecture seule : `scripts/v15_08_2_b_desktop_installable_preflight.py`. Il inspecte uniquement dix sources contractuelles explicitement nommées, refuse un SHA inexact, vérifie la présence de marqueurs de sécurité et l'absence du branchement LAB dans la salle d'attente historique ; il **ne valide pas sémantiquement** les protections ni un artefact de release.
```powershell
# Exécutable dans un checkout de développement isolé, jamais en profil cabinet.
$head = (git rev-parse HEAD).Trim()
py -3.12 scripts/v15_08_2_b_desktop_installable_preflight.py --expected-sha $head
py -3.12 -m pytest -q queue_core/tests/test_installable_source_preflight_08_2_b.py
```

Attendu et observé sur Windows Python 3.12 : **10/10 source guards présents**, `SOURCE_GATE_PRESENT_NO_INSTALLABLE_GO`, **5/5 tests ciblés PASS**, suite Queue Core finale **127/127 PASS en 95,37 s**, Python compileall/diff-check PASS. La commande `--json` rend le rapport détaillé exclusivement sur stdout ; aucune sortie fichier ni accès à une base clinique. Certificat, EXE et tests physiques restent explicitement `NOT_RUN`. Si un guard disparaît, EXIT non nul. La CI Queue Core exécute aussi les tests de source par `pytest queue_core/tests` au SHA du commit.
