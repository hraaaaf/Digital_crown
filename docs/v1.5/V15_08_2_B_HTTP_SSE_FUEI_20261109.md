## Architecture and security

Added queue_core/service/http_transport.py, an **opt-in FastAPI ASGI factory** (create_local_queue_app). It does not start or bind an HTTP server, install software, create a database, expose a WAN interface or attach to clinical data. Requires the existing AuthorizedLocalQueue, two separate initialized local SQLite databases and B-2 local operator sessions. The app is locked to loopback peer and loopback Host; lab_allow_testclient only admits TestClient's synthetic peer. There is no login route, no token-in-URL, no cookie sessions, no CORS enablement, no OpenAPI/docs endpoint, no remote access setup, and no long-lived authorization cache.

Routes exercised through the actual FastAPI ASGI TestClient (not just method mocks):

- POST /v1/visits/{visit_id}/commands — typed, extra-forbidden request containing command, expected_version, optional resource_id, optional reason_code. 401 before body validation for missing/invalid session. Live scope and transactional domain/event writes stay in AuthorizedLocalQueue.
- GET /v1/queues/{queue_id}/snapshot — minimal per-visit queue facts, fresh permission check.
- GET /v1/queues/{queue_id}/events — bounded, tenant+queue scoped, paginated event replay, cursor validation; dates and IDs only, no patient identity.
- GET /v1/queues/{queue_id}/stream — **real text/event-stream StreamingResponse** with bounded polling, Last-Event-ID scoped replay, event IDs, JSON data, and keepalive frames.

HTTP bearer is obtained only from the Authorization header and checked before parsing the request body. FastAPI transport never accepts caller-provided tenant, roles, actor or permission flag. All queue/visit/resource scopes resolve from server-side tables, with B-2 session rights rechecked inside queue transactions. SSE handshake validates token, queue and cursor before any 200 stream headers. Before *each individual SSE event* (including events buffered by an earlier poll) and heartbeat, the transport calls a fresh B-2/Queue Core authorization transaction; on disable/revoke it closes silently without sending a further event. SSE ID is a strict server-generated 32-hex UUID to block CRLF field injection. Replay never trusts a foreign queue cursor. Headers are no-store, nosniff, no-referrer and X-Accel-Buffering: no. Access errors are minimal 401/403 codes, validation errors a generic 422 without input echo.

**Important limitation:** a revocation that commits after the last per-frame check cannot retract bytes already handed to the ASGI transport or already on the socket. This cannot be solved by this adapter alone; no false guarantee of hard instant network cutoff. No production remote proxy/host or device access is permitted. A browser client must use authorized fetch streaming (native EventSource cannot set the required Authorization bearer header).

## Tests / FUE-I

Source: queue_core/tests/test_http_sse_08_2_b.py. Fixtures: same two temporary real SQLite files from queue_core/tests/test_service_auth_08_2_b.py with synthetic operators, queues and visits. Real HTTP handling via FastAPI TestClient, isolated event loop through anyio, plus negative ASGI non-loopback IP via httpx.ASGITransport. No real network listener or clinic inputs.

Oracles:
1. POST check-in→call→chair→done, GET snapshot and paginated events; exact persisted versions 0→2→3→5→7 and seven events.
2. No/malformed/unknown bearer and URL token are 401; a malformed anonymous body is rejected before schema disclosure; cookie credentials ignored; client actor/tenant/authorized injection rejected with safe 422.
3. Wrong queue, tenant, visit, assigned resource, implicit Admin queue operations: 403 and no mutation; static docs/OpenAPI disabled; hostile host 400 and non-loopback ASGI peer 403.
4. SSE event stream emits real text/event-stream frames, opaque 32-hex IDs and minimal JSON payload; valid Last-Event-ID resumes; cross-queue or nonexistent cursor is 403 before stream.
5. B-2 grant revoke between buffered SSE events terminates generator without releasing the second frame. A *real FastAPI SSE response* with deterministic revoke immediately before the second frame emits only the first, followed by old-session 401.
6. Bad/corrupt event id cannot inject additional SSE fields; response excludes session tokens, patient notes and free text.

FUE level: **FUE-I local ASGI integration**; no browser GUI or installed Windows app, so FUE-G / physical LOT10 NOT_RUN. An ASGI TestClient runs real HTTP request validation, middleware and StreamingResponse but does not prove a bound TCP socket, Windows firewall, TLS, native packaging or actual browser behavior. CI must exercise FastAPI/httpx pinned dependencies at the exact new SHA (the Queue Core CI workflow is amended accordingly).
